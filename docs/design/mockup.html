Cài đặt

Kết nối tới bucket Cloudflare R2 chứa thư viện nhạc.

Cloudflare R2

Đang lưu secret kết thúc bằng a1b2. Để nguyên để giữ, hoặc nhập giá trị mới.

App Android đọc catalog.json và file nhạc qua URL này.

Kết nối thành công · đọc được catalog.json (8 bài)

Trước khi kết nối

  • Bucket cần bật public access (r2.dev hoặc domain riêng).
  • Không bật nén cho audio và ảnh. Range request mặc định đã hoạt động.
  • Key chỉ nằm trong máy này, app Android không bao giờ cầm key.
